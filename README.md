## วิธีเปิด

ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เพราะเบราว์เซอร์อ่านไฟล์ CSV จาก `file://` ไม่ได้

- **Windows:** ดับเบิลคลิก `start_dashboard.bat` (ต้องมี Python 3) แล้วเปิด http://localhost:8000/dashboard_claude.html (ส่วน http://localhost:8000 คือเวอร์ชัน ECharts ใน `index.html`)
- **วิธีอื่น:** รันคำสั่งนี้ในโฟลเดอร์โปรเจกต์ แล้วเปิด http://localhost:8000/dashboard_claude.html

```bash
python -m http.server 8000
```

ต้องต่ออินเทอร์เน็ต เพราะฟอนต์ Kanit, Chart.js 4.4.1 และ PapaParse 5.4.1 โหลดจาก CDN

## การใช้งาน

- **ปีและเดือน** ใช้ร่วมกันทั้ง 3 แท็บ และยังคงค่าเดิมเมื่อสลับแท็บ
- **คลิกได้ทุกอย่างและเชื่อมกันภายในแท็บ:** แท่งกราฟ ส่วนของแท่งซ้อน จุดบนกราฟเส้น (เลือกปีและเดือนให้ทุกแท็บ) การ์ด KPI คำอธิบายสี ป้ายในตาราง และชื่อหมวดใน small multiples ทั้งหมดนี้เป็นตัวกรอง คลิกซ้ำเพื่อยกเลิก
- ตัวกรองต่างมิติใช้ AND · กราฟที่เป็นต้นทางของตัวกรองยังแสดงทุกค่า แต่ทำให้ค่าที่ไม่ได้เลือกจางลง
- ตัวกรองหมวดหรือคำสำคัญ**ไม่ส่งข้ามแท็บ** เพราะเป็นคนละฐานข้อมูล (REQUIREMENTS FR-03, AC-06)
- ป้ายตัวกรอง (chip) แสดงใต้แถบตัวกรอง · ปุ่ม "ล้างตัวกรองแท็บนี้" / "ล้างทั้งหมด" · ปุ่มลัด `1` `2` `3` สลับแท็บ, `Esc` ล้างทั้งหมด
- ทุกตัวกรองที่คลิกได้มี dropdown บนแถบด้านบนให้ใช้ด้วยคีย์บอร์ดด้วย
- "สรุป 3 มุมมอง" แสดง Key Findings จากข้อมูลจริงตามปีและเดือนที่เลือก
- ตารางค้นหา เรียง แบ่งหน้า และดาวน์โหลด CSV ตามตัวกรองได้ โดยไฟล์จะมีบรรทัดระบุแหล่ง ช่วง และตัวกรองไว้ด้านบน

## กติกาข้อมูลที่ใช้

- KPI ทุกตัวคำนวณจากแถวหลังกรอง ไม่มีตัวเลข hard-code
- **EU:** นับเรื่องด้วย `debunk_id` ไม่ซ้ำ · ตัวกรองภาษา โดเมน และประเภทบทความ กรองที่ระดับบทความแล้วนับ `debunk_id` กลับแบบไม่ซ้ำ · คำสำคัญแยกด้วย `,` ตัดช่องว่าง และรวมตัวพิมพ์เล็ก/ใหญ่ (มี 1 คู่: "War crimes" / "war crimes") · 17 เรื่องไม่มีคำสำคัญ ซึ่งแจ้งไว้ใต้กราฟ
- **Thai:** กราฟที่นับเฉพาะ Fake (T1, T3, T4) แสดงข้อความแจ้งเมื่อเลือกผลตรวจสอบอื่น ไม่ละเลยตัวกรองโดยไม่บอก · T4 ใช้แกน Y เดียวกัน
- **Gate (`src/config.js`):**
  - `aiHarmedMappingApproved: false` → กราฟ A4 แสดงข้อความ harmed จากต้นฉบับแทนการจัดอันดับ เปลี่ยนเป็น `true` หลังกลุ่มตรวจ `mappings/ai_harmed_mapping_draft.csv`
  - `euTopicMappingApproved: false` → กราฟ E3 ใช้ article class แยกปีเป็นกราฟสำรอง (ยังไม่มี topic mapping)
